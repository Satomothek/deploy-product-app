Folder ini berisi kode `lib/` (model, API service, halaman CRUD) dan `pubspec.yaml`
agar dependency Flutter dan `http` dapat dikenali saat kode dianalisis di folder ini.
Jalankan `flutter pub get` lalu `flutter analyze` untuk memeriksa kode.

Untuk menjalankan aplikasi, ikuti PANDUAN.md, Tahap 5: buat project Flutter baru,
tambahkan dependency `http`, lalu salin folder `lib/` ini ke project tersebut.
